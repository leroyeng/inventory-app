# Inventory Management App

A command-line inventory management application built with C# and SQLite.

## Features
- View all inventory items sorted by category
- Add new items with name, category, quantity, and price
- Update item quantities
- Delete items
- Search items by category

## Tech Stack
- C# / .NET 8
- SQLite (via Microsoft.Data.Sqlite)

## How to Run
1. Install [.NET 8 SDK](https://dotnet.microsoft.com/download)
2. Clone the repository
3. Run the following commands:

git clone https://github.com/leroyeng/inventory-app.git
cd inventory-app
dotnet run
